# Worldloom v1.0.0

Worldloom v1 turns public activity into one persistent, collaborative living-fiber
artwork built with Phoenix LiveView and OTP.

## Highlights

- Wikimedia activity, USGS earthquakes, and global Open-Meteo observations have
  distinct deterministic visual forms.
- Anonymous visitors can add a Tug, Knot, or Illuminate gesture without registering.
- PostgreSQL-backed sequences and versioned drawing instructions survive application
  restarts and reopen through stable UTC chapter permalinks.
- Independent supervised feed workers, bounded ingestion, durable checkpoints, and
  sequence-gap repair keep degraded operation honest and recoverable.
- Keyboard, pointer, and touch interaction; visible focus; textual summaries;
  responsive controls; and reduced-motion rendering are included from the first
  release.
- Public privacy, source-attribution, architecture, operations, contribution, and
  security documentation ship with the MIT-licensed source.

## Deliberate v1 limits

- One application instance owns the authoritative coordinator. Multi-node leadership
  is not implemented.
- Open-Meteo's free endpoint is used only for this non-commercial public artwork.
- Historical normalized events are retained while 30-day growth is measured.
- Accounts, profiles, chat, uploads, custom colors, scores, and social preview images
  are outside the release.
